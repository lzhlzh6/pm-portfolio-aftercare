## 这个项目是什么

**售后管家**是面向中小电商商家的售后工单处理平台，核心思路是用 AI 把"退款审核"这个高频、低门槛、但占满客服人力的环节自动化，让人工只处理真正需要判断的异常单。

产品名 AfterCare，定位是"售后环节的自动驾驶"。

## 建议重点看这三处

1. **退款自动审核决策树**（04-流程图）— 把"要不要退"这个模糊判断拆成可执行的规则与阈值，是整个产品的核心逻辑。
2. **PRD 的需求条目写法**（05-PRD）— 每条需求都带前置条件、异常分支和验收标准，不写"支持 XX"这种空话。
3. **原型里的退款审批页**（06-原型）— 原型上标出了每一步的 `decision_path`，能直接看到 AI 决策过程，而不只是点得动的图片。

## 关于数据来源

本作品集为**个人产品设计练习**，基于公开的行业资料与合理的商业推演完成，非真实商业计划。

文档中所有关键假设（如退款阈值、各类超时阈值、客服并发上限等）均在对应文档的「待验证假设」章节中明确标注，未把推演数据包装成实测结果。
